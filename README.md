# Bank Management Application

A console-based Bank Management Application developed in C++ using Object-Oriented Programming (OOP) and file handling.

## Features

- Create a new bank account
- Display all account records
- Check account balance
- Deposit money
- Withdraw money
- Persistent account records using file handling
- User-friendly console interface
- Menu-driven program

## Technologies Used

- **Language:** C++
- **Concepts:** Object-Oriented Programming (OOP), Classes & Objects, Encapsulation, File Handling, Functions, Loops and Conditional Statements
- **Compiler:** GCC / MinGW

## How to Run

### Using VS Code

1. Open the project folder in VS Code.
2. Open the terminal.
3. Navigate to the project folder.
4. Compile the program using:

```bash
g++ BankManagementSystem.cpp -o BankManagementSystem
```

5. Run the program using:

```bash
./BankManagementSystem
```

### Windows

After compilation, you can also run:

```text
BankManagementSystem.exe
```

## File Storage

The application stores account records in:

```text
accounts.dat
```

The data file is created automatically when accounts are added.

The generated `.dat` and `.exe` files are excluded from GitHub using `.gitignore`.
